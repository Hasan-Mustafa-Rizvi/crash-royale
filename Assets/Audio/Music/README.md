# Music

Music files are not included in the repository. The game runs fine without them (sound effects are included).

To add music, drop two tracks in this folder and run **Crash Royale > Rebuild Content and Scenes**:

- a file whose name starts with `menu` (played in the menus)
- a file whose name starts with `battle` (played during battles)

`.wav`, `.mp3` and `.ogg` all work. Loops sound best.
